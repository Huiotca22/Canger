# Security Policy

## Supported versions

Security fixes are provided for the latest release on the `main` branch.

## Reporting

Do not open a public issue for an unfixed vulnerability. Send a private report to the repository maintainers with:

- affected version and platform;
- minimal reproduction steps;
- relevant logs with secrets removed;
- impact and suggested mitigation.

Do not include CurseForge keys, session tokens, usernames or personal paths in a report.
